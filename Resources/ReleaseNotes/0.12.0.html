Savenest 0.12.0 — Read & note

  • Open the current tab or a selected page in a dedicated workspace: original webpage on the left, your Obsidian Markdown note on the right.
  • Choose your vault and notes folder. Savenest starts with your vault’s configured new-note folder when available.
  • Write with autosave, Markdown formatting, source mode, recovery drafts, and protection against conflicting external edits.
  • Resize the panes, switch between light and dark themes, and reopen the same page to return to its note.
  • Original opens automatically. Optional Reader view needs your browser’s “Allow JavaScript from Apple Events” setting; Original does not need that JavaScript permission.

Original uses a separate temporary browser session. Browser logins are not shared. Notes become real Markdown files in your chosen vault when you write.

This remains a preview. Export a library backup before upgrading. Full installed-app migration, Intel runtime, and cloud-synced concurrent-edit checks remain pending.
