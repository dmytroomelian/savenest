Savenest 0.15.1

  • Help now gathers Explore features, Request a feature, Report a bug, and Keyboard shortcuts in one compact launcher-footer menu.
  • Explore features keeps the existing searchable catalog, including Pro and Beta entries. It is still available from root search, Actions, and the macOS Help menu, but is no longer a default quick action.
  • Settings moves its feedback links to the footer. Account feedback is unchanged.
  • Release preparation now uses a frozen source snapshot, a read-only --plan, parallel arm64 and x64 stages, automatic package validation, and safe resume for pending notarizations. Universal remains required.
  • Release tooling adds publication planning and verification commands and uses the canonical dmytroomelian/savenest repository.
  • No performance improvement is claimed. Installed-app upgrade behavior and Intel runtime validation remain pending.
