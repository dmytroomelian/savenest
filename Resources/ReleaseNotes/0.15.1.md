# Savenest 0.15.1

- **Help menu:** Explore features, Request a feature, Report a bug, and Keyboard shortcuts now live in one compact menu in the launcher footer.
- **Explore features:** the existing searchable catalog, including Pro and Beta entries, is unchanged. It remains in root search, Actions, and the macOS Help menu, but is no longer a default quick action.
- **Feedback:** Settings shows feedback links in its footer; Account feedback is unchanged.
- **Release reliability:** preparation uses a frozen source snapshot, a read-only `--plan`, concurrent arm64/x64 stages, automatic archive validation, and safe resume of pending notarizations. The universal archive remains mandatory.
- **Publication:** new planning and verification commands use the canonical `dmytroomelian/savenest` repository.

No benchmarked speed improvement is claimed. Installed-app upgrade behavior and Intel runtime validation remain pending.
