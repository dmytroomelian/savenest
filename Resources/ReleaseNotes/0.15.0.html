Savenest 0.15.0

  • Activity dashboard: a Monday-first yearly calendar and daily feed. Yearly counts show saved and finished links plus links still to finish across the library. Archiving counts as finished; older undated archives are reported separately instead of being assigned an invented date.
  • Select links with checkboxes, Shift-Space, Command-click, or Shift-click; select all visible with Shift-Command-A. Bulk actions save, copy, favorite, archive, restore, or delete selected links. Results show site icons.
  • macOS Services: select a complete web URL and choose Services → Add to SaveNest… to open a note-and-tags draft. Nothing is saved until you confirm.
  • Optional Launch at login is available in Settings → General.
  • Settings and Account open more reliably from the launcher, including capture and tag settings, without losing the current launcher context.
  • Feedback entry points are available in Settings, Account, the macOS Help menu, Actions, and root search.
  • Installation and duplicate-instance handling are safer: the app installs under its canonical name, never overwrites an existing copy, and keeps one active library writer.
  • Existing optional anonymous usage counts keep their current opt-out and are also reported to the configured PostHog project.
  • Save from other apps remains an optional Pro beta. Free local saving, reading, search, and organization are unchanged.
  • Installed-app upgrade behavior and Intel runtime validation remain pending.
