# Security reporting

Please report vulnerabilities privately to [dima@omelabs.org](mailto:dima@omelabs.org) with the subject “Savenest security report”. Do not open a public issue containing exploit details, credentials, or personal data.

Include the affected version, a minimal reproduction using synthetic data, expected and actual behavior, and the likely impact. Do not send your library, browsing history, session token, or a complete production log.

Reports cover the current public release and main-branch source. A response deadline or bug-bounty payment is not promised. We will review the report, coordinate a fix where appropriate, and agree on disclosure details with the reporter.

Ordinary bugs and feature requests belong in [GitHub issues](https://github.com/dmytro-omelian/savenest/issues). For data handling, see the [privacy policy](https://savenest.app/privacy).
